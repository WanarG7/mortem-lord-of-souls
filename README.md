## 🎮 Proje Hakkında
**Mortem: Lord of Souls**, üniversite Oyun Stüdyosu dersi kapsamında geliştirilmiş; gotik karanlık atmosferi, hızlı tırpan dövüş dinamiklerini, nekromansi yeteneklerini ve her turda farklı build'ler kurmayı sağlayan kart/lütuf sistemini bir araya getiren bir roguelike aksiyon oyunudur.

## ✨ Öne Çıkan Özellikler
* **Nekromansi & Ordu Mekaniği:** Düşen cesetleri dirilterek kendi minyon ordunuzu kurma, gerektiğinde cesetleri patlatma veya feda ederek Azrail formuna geçme.
* **Hızlı Aksiyon & Vuruş Hissi:** Tırpan saldırıları, seri atılma (dash) ve fare yönelimli akıcı dövüş dinamikleri.
* **30+ Kart & Lütuf Sistemi:** Her oda tamamlandığında açılan 3'lü kart seçim havuzundan tura özel güçlendirmeler elde etme.
* **Gotik Piksel Atmosfer:** Zindan odaları, ölümcül tuzaklar, meşaleler ve düşman dalgaları.

## ⌨️ Kontroller

| Tuş | İşlev |
| :--- | :--- |
| **W, A, S, D** / **Yön Tuşları** | Karakter Hareketi |
| **Fare Hareketi** | Nişan Alma / Bakış Yönü |
| **Space (Boşluk)** | Atılma (Dash) |
| **Sol Tık (LMB)** | Tırpan / Temel Saldırı |
| **Sağ Tık (RMB)** | Ceset Diriltme (Minyon Ordusu Çağırma) |
| **E** | Ceset Patlatma (AOE Hasar) / Silah Kuşanma |
| **Q** | Minyonları Feda Ederek Azrail Moduna (Reaper Form) Geçiş |
| **1, 2, 3** veya **Sol Tık** | Lütuf / Silah Kartı Seçimi |
| **R** | Öldükten Sonra Yeniden Başlatma |
